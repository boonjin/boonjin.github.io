# boonjin.com

Personal site and writing for Boon Jin.

This site is built with Astro, stored as plain Markdown, and deployed to GitHub Pages from the `main` branch.

## Common Commands

```bash
npm install
npm run dev
npm run build
```

## Writing Posts

Add posts in `src/content/posts/`.

Use this frontmatter shape:

```md
---
title: "Post title"
description: "Short SEO and social description."
date: 2026-05-02
tags: ["AI", "EdTech"]
image: "/images/classroom-ai-singapore.png"
---
```

Future Codex agents should keep posts factual, concise, and grounded in Boon Jin's actual product work: Smoothboard, Deck.Toys, practical AI for teachers, and solo-founder work in Singapore/SEA.
